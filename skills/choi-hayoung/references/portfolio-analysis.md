# 포트폴리오 분석 계약

## 필요한 맥락

가능하면 투자 목표, 기간, 기준통화, 현금흐름과 유동성 필요, 위험 감수도, 세금·계좌 제약, 기존 포지션의 수량·평균단가·현재가 기준을 확인한다. 정보가 없으면 합리적인 가정을 명시하되 주문이나 개인화된 확정 결론으로 위장하지 않는다.

## 분석 순서

1. 각 포지션의 정확한 상품 정체성과 통화를 묶는다.
2. 가격의 관찰 시각과 세션을 맞추고 평가액과 비중을 계산한다.
3. 자산군·산업·요인·지역·통화·만기·유동성 집중도를 본다.
4. 상관관계와 공통 위험요인이 분산처럼 보이는 중복을 찾는다.
5. 사용자의 목표와 제약에 비춰 감당 가능한 손실과 시나리오를 비교한다.
6. 유지·감축·추가 검토를 조건으로 표현하고 우선순위를 제시한다.

## 통합 근거 순서

혼합 투자 질문에서는 먼저 World Memory의 기존 가설과 무효화 조건을 읽고, 현재 뉴스로 강화·약화 여부를 확인한 다음, 포트폴리오 스킬로 가격·기초체력·밸류에이션·포트폴리오 영향을 검증한다. 서로 다른 날짜·통화·제공자·가격 기준을 평균내지 않는다.

## 백테스트

사용자가 명시적으로 요청했을 때만 실행한다. 생존편향, 룩어헤드, 데이터 가용시점, 리밸런싱, 배당·분할, 거래비용, 세금, 환율, 현금 처리, 벤치마크를 기록한다. 데이터 실패 시 임의 종목이나 임의 비중으로 대체하지 않는다. 결과 표와 ChatGPT Work의 내장 차트는 정확성을 위해 유지할 수 있으며, 하영의 서사가 이를 둘러싼다.

## 행동 조언

매수·매도 명령 대신 판단 규칙을 준다. 예: 어떤 근거가 유지되는 동안 보유 가설이 성립하는지, 어떤 가격·실적·신용·거시 조건이 깨지면 재검토할지, 한 번의 행동 대신 분할·관찰·헤지의 장단점이 무엇인지 밝힌다.
